# Strudel : documentation et créations personnelles

Dépôt personnel autour de [Strudel](https://strudel.cc), environnement de **live coding** musical dans le navigateur (héritier de l’écosystème TidalCycles). Il regroupe de la documentation de référence et mes propres **patterns**, **morceaux** et **expérimentations** en cours d’apprentissage.

## Contenu du dépôt

| Dossier | Rôle |
|---------|------|
| [`docs/`](docs/) | Guides PDF, références et notes pour apprendre Strudel (copie locale, hors ligne). Voir le [readme du dossier](docs/readme.md). |
| [`samples/`](samples/) | Exemples de code Strudel : sketches, essais et idées à rejouer dans le [REPL](https://strudel.cc). |

## Strudel en bref

Strudel permet d’écrire de la musique algorithmique en **JavaScript** ou en mini-notation inspirée de Tidal, de la jouer en direct dans le navigateur et de l’utiliser pour des performances ou l’apprentissage du code créatif. Le son suit le code grâce à un **REPL** (*Read–Eval–Print Loop*) : vous écrivez une expression, l’environnement l’évalue aussitôt et rejoue le résultat - pas besoin de recompiler ni de relancer quoi que ce soit.

Documentation officielle : [strudel.cc](https://strudel.cc/workshop/getting-started/) - manuel technique du REPL : [technical-manual/repl](https://strudel.cc/technical-manual/repl/)

## Conditions d’utilisation

### Interdiction d’usage pour l’IA

**Je refuse explicitement** que le contenu de ce dépôt (code, textes, PDF, audio éventuel, captures, etc.) soit utilisé pour :

- alimenter, scraper ou indexer des corpus destinés à des **modèles d’IA** ;
- **entraîner**, affiner ou évaluer des systèmes d’apprentissage automatique ;
- produire des dérivés automatiques (génération de code, de texte ou de musique « à la manière de » ce dépôt).

Si vous développez ou exploitez un service d’IA : **n’intégrez pas** ce dépôt dans vos jeux de données, crawlers ou pipelines d’entraînement, sauf accord écrit de ma part.

### Samples : réutilisation humaine bienvenue

En revanche, les fichiers dans [`samples/`](samples/) sont là pour être **repris à la main** :

- copier-coller dans le REPL Strudel ;
- modifier, découper, combiner avec vos propres idées ;
- apprendre en expérimentant vous-même.

Vous êtes **libres** de vous en inspirer pour vos sessions de live coding ou vos ateliers, tant que l’usage reste **manuel et créatif** (pas d’ingestion massive pour entraîner une machine).

### Documentation tierce

Les PDF et ressources dans `docs/` peuvent être soumis à leurs **propres licences** (auteurs originaux). Ce dépôt ne revendique pas leur paternité ; il les archive pour un usage personnel et pédagogique.
