# Documentation Strudel

Ce dossier regroupe des **guides et références en PDF** pour apprendre [Strudel](https://strudel.cc) : copies locales à consulter **hors ligne**, en complément de la [documentation en ligne](https://strudel.cc/workshop/getting-started/).

## Fichiers

| Fichier | Rôle |
|---------|------|
| [`Strudel-Guide.pdf`](Strudel-Guide.pdf) | Guide général : prise en main, concepts et repères pour naviguer dans l’outil. |
| [`Strudel-Le-playbook.pdf`](Strudel-Le-playbook.pdf) | Playbook : recettes, exemples et pistes pour composer et improviser au REPL. |
| [`mclean_roos_strudel.pdf`](mclean_roos_strudel.pdf) | Document de référence (McLean & Roos) sur Strudel et son contexte (live coding, Tidal). |

## Utilisation

1. Ouvrir le PDF adapté à ce que vous cherchez (démarrage, pratique, théorie).
2. Travailler en parallèle avec le [REPL](https://strudel.cc) pour tester les idées sur le vif.
3. Compléter avec le [manuel technique du REPL](https://strudel.cc/technical-manual/repl/) lorsque la doc officielle fait foi.
