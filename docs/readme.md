# Strudel - documentation

Ce dépôt sert à **centraliser et mettre à disposition** différentes ressources documentaires autour de [Strudel](https://strudel.cc), un outil de **live coding** dans le navigateur (héritier de l’écosystème TidalCycles).

## Objectif

Strudel.cc propose déjà une documentation en ligne, des tutoriels et des références d’API. Ce dossier permet de :

- regrouper des **guides**, **notes** et **références** annexe pour enrichir cet apprentissage.
- conserver une **copie locale** (hors connexion) de la documentation.

## Contenu prévu

On y trouvera par exemple :

- prise en main et concepts (patterns, cycles, effets) ;
- référence des fonctions et syntaxe ;
- exemples de morceaux ou d’exercices ;

Documentation officielle : https://strudel.cc/technical-manual/repl/
