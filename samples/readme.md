# Samples Strudel

Ce dossier regroupe du **code Strudel** prêt à être copié dans le [REPL](https://strudel.cc) : essais d’apprentissage d’un côté, morceaux « officiels » de l’autre.

## Structure

| Dossier | Contenu |
|---------|---------|
| [`experimentation/`](experimentation/) | Morceaux et sketches que je compose **pour apprendre** : tests de sons, d’effets, de structures. Rien n’est figé ; tout peut changer ou servir de brouillon. |
| [`onrigoleplus/`](onrigoleplus/) | **Vrais morceaux finaux**, chacun avec un **nom** : répertoire que j’utilise pour mes **sessions de live coding**. Versions que je considère prêtes à être jouées en public. |

## Utilisation

1. Ouvrir [strudel.cc](https://strudel.cc).
2. Ouvrir le fichier `.js` voulu, copier le code dans l’éditeur.
3. Lancer l’évaluation (le REPL met à jour le son à la volée).

Les conditions d’utilisation du dépôt (notamment **pas d’usage pour entraîner des IA**, réutilisation **manuelle** bienvenue) sont détaillées dans le [readme à la racine](../readme.md).
